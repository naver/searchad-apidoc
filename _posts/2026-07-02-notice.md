안녕하세요. 네이버 검색광고 API 운영자 입니다. <br>

검색광고 계정 통합이후  구 검색광고의 Agent에 대한 탈퇴 처리 및 개인정보 폐기 과정에서, 일부 Agent의 검색광고 API 비밀키 변경이 확인되었습니다. 

현재 영향을 받은 Agent에 대해 파악중입니다.

API 호출시 비밀키가 바뀐걸로 응답을 받으면, 광고주센터에서 새로운 API 키를 확인후 적용 또는 재발급하여 적용하시면, 동일 오류는 발생하지 않습니다. 

이번 오류는 API키 변경외에 영업권관련 오류는 발견되지 않았습니다. 

불편을 드린점 사죄 드리며, 업무에 참고 부탁드립니다.

감사합니다.
