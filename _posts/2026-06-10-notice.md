안녕하세요? 네이버 검색광고 API입니다.

[Campaign API](https://naver.github.io/searchad-apidoc/#/operations/PUT/~2Fncc~2Fcampaigns) 및 AdExtension API의 노출 기간 필드(`periodStartDt`, `periodEndDt`)에 대한 검증이 강화됩니다.

해당 필드는 **한국시간(KST) 자정을 UTC로 표현한 값**만 허용되며, 시·분·초가 포함된 값을 전달할 경우 `400 Bad Request`가 반환됩니다.

- 올바른 예시 : `2026-06-01T15:00:00.000Z` (= KST 2026-06-02 00:00:00)
- 잘못된 예시 : `2026-06-01T00:00:00.000Z` (UTC 자정 = KST 09:00:00)

해당 필드를 사용 중이신 경우, 전달 값을 확인해 주시기 바랍니다.
신규 API 관련 내용은 별도 공지사항을 통해 안내 드리겠습니다.

#### 변경일시 (KST 기준)
- 2026년 6월 10일 : 검증 로직 적용 (시·분·초 포함 시 400 반환)

감사합니다.

Hello. This is Naver Search Ads API.

Validation for the `periodStartDt` and `periodEndDt` fields in the [Campaign API](https://naver.github.io/searchad-apidoc/#/operations/PUT/~2Fncc~2Fcampaigns) and AdExtension API will be strengthened.

These fields only accept values representing **KST midnight expressed in UTC**. Requests containing a time component will be rejected with `400 Bad Request`.

- Valid example : `2026-06-01T15:00:00.000Z` (= KST 2026-06-02 00:00:00)
- Invalid example : `2026-06-01T00:00:00.000Z` (UTC midnight = KST 09:00:00)

If you are currently using these fields, please verify that the values being sent are correct.

#### Date of Change (based on KST)
- 2026 X월 X일 : Validation applied (400 returned if time component is included)

Thank you.
