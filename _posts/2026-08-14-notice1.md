title: 확장 소재 보고서 항목 삭제 안내 (STAT-REPORT)
categories: [notice]
---

안녕하십니까 네이버 검색광고 API입니다.<br>

 확장 소재 관련 대용량 리포트에서 제공 중인 'AD extension Business Channel ID' 항목이 삭제되어 안내드립니다. <br>

1. **대상 보고서**<br>
   - 확장 소재 광고 성과 보고서 (reportTp: ADEXTENSION)
   - 확장 소재 전환 보고서 (reportTp: ADEXTENSION_CONVERSION)

2. **변경 시점(KST기준)**
   - 2026년 11월 16일 (월)

3. **변경 내용**<br>
   - 두 보고서의 8번 'AD extension Business Channel ID' 항목이 삭제됩니다.
   - 항목 삭제에 따라 9번 이후 항목의 열순서가 한 칸씩 당겨집니다.
     - 확장 소재 광고 성과 보고서 : 전체 15개 항목 → 14개
     - 확장 소재 전환 보고서 : 전체 14개 항목 → 13개
   - 변경 시점 이후 생성되는 보고서는 기준일자와 무관하게 해당 항목이 제공되지 않습니다.<br>
**확장 소재 광고 성과 보고서 (reportTp: ADEXTENSION)**

| 변경사항 | 열순서 | 열이름 | 데이터형 | 설명 |
| --- | --- | --- | --- | --- |
| 변경 없음 | 1 | Date | String | 보고서의 기준일자입니다. |

| 변경 없음 | 3 | Campaign ID | string | 광고 성과가 발생한 캠페인의 고유 아이디입니다. |
| 변경 없음 | 4 | AD Group ID | string | 광고 성과가 발생한 광고그룹의 고유 아이디입니다. |
| 변경 없음 | 5 | AD keyword ID | string | 광고 성과가 발생한 키워드의 고유 아이디입니다. |
| 변경 없음 | 6 | AD ID | string | 광고 성과가 발생한 소재의 고유 아이디입니다. |
| 변경 없음 | 7 | AD extension ID | string | 광고 성과가 발생한 확장 소재의 고유 아이디입니다. |
| ➖삭제 | 8 | AD extension Business Channel ID | string | 확장 소재에 연결된 비즈채널의 고유 아이디입니다. |

| 열순서 변경 | 12 → 11 | Click | int | 클릭수입니다. |
| 열순서 변경 | 13 → 12 | Cost | long | 광고비입니다. |
| 열순서 변경 | 14 → 13 | Sum of AD rank | int | 노출 순위의 합입니다. 평균 노출 순위 = Sum of AD rank / Impression |
| 열순서 변경 | 15 → 14 | View count | int | 동영상 재생수입니다. |

4. **참고 사항**
   - 확장 소재의 비즈채널 정보는 확장소재 마스터 (item = AdExtension)의 5번 Business channel ID(PC), 6번 Business channel ID(Mobile)를 통해 계속 확인하실 수 있습니다.
   - 변경 시점 이전에 이미 생성된 보고서에는 변경 사항이 반영되지 않습니다.
